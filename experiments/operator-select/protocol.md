# 固定方案：三数选符号（与自由生成实验分开）

给出 `(a ? b) + c = target`，模型只选 `+`、`-`、`*`。应用三者中的任一符号都是合法算式，仅结果相等得 1 分，否则 0 分。没有示范答案、监督微调或格式奖励。研究问题是：在有限动作空间、有可验证反馈时，策略训练能不能改变留出题的正确率？这不是开放算术测验。

先固定以下方案，再训练和打开测试结果：

- `Qwen/Qwen2.5-0.5B-Instruct` 同一快照，LoRA rank 16。三组独立训练种子 2026（主报告）、2027、2028；不选最高的一个。
- 数字范围 2–28，三数互不相同，每个无序数字组合只出现一次。固定题库种子 74103；划分 1800 训练 / 240 验证 / 600 测试，每部分三类符号各占 1/3。每个组合打乱三个位置。只把题干给模型。此题型可以部分利用目标数的大小，不等同于学会精确计算。
- 每次从未更新的底模开始，固定 240 次更新，batch 24。每题按策略抽 12 个符号，实际执行算术判分，用组内中心化优势做一步策略梯度更新。采样策略是温度 1.4 的三符号 softmax 混合 20% 均匀探索；优化同一混合策略的 log 概率，另有 0.025 的熵奖励。AdamW 学习率 0.00012，梯度裁剪 1.0。
- 验证轨迹每 20 步记录一次；不挑最佳检查点。主指标为固定末步与未更新模型在**同一 600 题、相同贪心解码**上的算式正确率差。报告主种子的错转对、对转错、配对 bootstrap 95% 区间、双侧精确 McNemar 检验；另两次单列，同一测试集不合并为 1800 道题。
- 教学成功标准：主种子绝对提升至少 15 个百分点且 p < 0.01；任何结果都保留。补充目标数大小捷径基线作为解释，不代替主指标。
